# Bybit Scalper Terminal — Stage 5.18

Mobile-first dedicated Scalp Mode.

- SC button on chart toggles Scalp Mode and persists locally.
- Hides Volume/RSI/MACD for a clean one-screen scalp view.
- Keeps chart, price/score and B/S visible.
- Adds large one-handed LONG / SHORT actions in the mobile trade dock.
- Gear button returns to the full trade configuration panel.
- Existing realtime, trading backend, Multi-TP and AUTO S/R mechanics are preserved.
- Trading remains disabled unless explicitly enabled on the server.
